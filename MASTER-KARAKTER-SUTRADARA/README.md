# MASTER KARAKTER SUTRADARA

**AI Cinematic Director · Character Continuity Engine · Video Prompt System**

Standalone project folder for a reusable AI filmmaking framework. This project is kept separate from KASIWAS-AI and CodeOnTheGo.

## Purpose
- Lock master character identity and visual attributes.
- Turn ideas into production-ready scene, storyboard, shot, and video prompts.
- Maintain continuity between shots and clips.
- Direct camera, lens, framing, lighting, blocking, action, audio, and transitions.
- Adapt prompt output for Sora, Google Flow/Veo, Runway, Kling, and other video models.

## Folder Structure
- `01_MASTER_PROMPT/` — Director system prompt and operating instructions
- `02_CHARACTER_BIBLE/` — Character identity, reference, traits, locks
- `03_PROJECT_PREFILL/` — Project setup and creative brief
- `04_STORYBOARD/` — Scene and shot planning
- `05_VIDEO_PROMPTS/` — Platform-ready prompt output
- `06_CONTINUITY/` — Clip continuity records and last-frame notes
- `07_QC/` — Quality-control checklists
- `08_PRESETS/` — Platform-specific prompt presets

## Core Commands
`PREFILL`, `LOCK CHARACTER`, `LOCK SCENE`, `LOCK COSTUME`, `STORYBOARD`, `RUN`, `NEXT CLIP`, `EXTEND`, `CHANGE CAMERA`, `CHANGE ACTION`, `REVIEW CONTINUITY`, `REMAKE SHOT`, `MASTER LOCK`.

## Principle
The master character reference and approved project bible are the sources of truth. Do not alter locked identity or continuity details without explicit user instruction.
